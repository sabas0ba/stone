# cc7 説明文書

cc7 は C コンパイラである。第 2 部の 5 の [cc6.sc](cc6.sc) を出発点に，
**初期化子を入れた** もの (第 3 部の 1)。
設計は [stage010-c89.md](../docs/stage010-c89.md) 15 章，出力形式は
[stage008-elf-ld.md](../docs/stage008-elf-ld.md) を参照。

ソース [cc7.sc](cc7.sc) が正本である。バイナリはビルドで再現される生成物で
あり，git 管理しない。

## ビルド

```
sh tools/build.sh stage010
# ... -> cc10f -> cc10g0 (ブートストラップ) -> cc10g (= cc.bin)
```

SHA-256: 0d3bd9960daf7edefedd8afd4bb5a610a8cc7a61b66d73c8405e8195c1f10e25

- 対象: RV32IM，リトルエンディアン，129268 バイト
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

## 第 2 部の 5 からの変更点

| 追加 | 内容 |
|---|---|
| 大域の初期化子 | `int g = 1;` `int a[] = {1,2};` `char s[] = "x";` `char *p = "x";` `int *q = &g;` `int (*f)(int) = fn;` |
| 局所の初期化子 | `int a = 5;` `int t[4] = {7,8};` `char s[6] = "hi";` |
| 多次元 | `int m[2][2] = {1,2,3,4};` 平らに並べる (入れ子の波括弧は無い) |
| データの配置 | 初期値を持つ大域は `.text`，持たない大域は従来どおり `.bss` |

コード生成規則は変えていないので，cc10f が作った 1 段目 (`cc10g0.bin`) と
それが自分自身を再コンパイルしたもの (`cc10g.bin`) はバイト単位で一致する。

## 実装上の要点

### 初期値のあるデータは `.text` に置く

普通のコンパイラは `.data` 節を作るが，ここでは作らない。対象が
ベアメタルで MMU が無く像はフラットに読み込まれるため，節の保護属性に
意味が無いからである。`.text` に置けば

- オブジェクト形式もリンカも変えずに済む
- データの中のポインタが既存の `.rela.text` の `R_RISCV_32` で解ける

記号ごとに置き場が 2 通りになるので，ELF シンボルの `st_shndx` を
1 (`.text`) と 2 (`.bss`) で書き分ける。`gtxt[]` がその印である。

### 文字列リテラルの実体は初期化子の後ろへ回す

`char *p = "abc";` は「`p` の実体 (ポインタ 1 語)」と「`"abc"` の実体」の
2 つを `.text` へ置く。読みながら文字列を出すと `p` の実体がその後ろへ
ずれ，先に確定させた記号の値が文字列の先頭を指してしまう。

そこで **文字列は番号だけ予約し，実体は初期化子を書き終えてから出す**。
仕組みは関数本体の文字列プール (`spool`) と同じで，出す再配置の種別だけが
違う (本体は `HI20`+`LO12_I` の 2 語，初期化子は `R_RISCV_32` の 1 語)。

```
gstrq()      文字列を spool へ積み，ローカルシンボル番号を予約する
gstrflush()  初期化子を書き終えた後に実体を出し，lsoff を埋める
```

### 局所の初期化子は宣言位置の代入である

局所変数の実体は毎回フレーム上に作られるので，初期値は宣言のある位置で
実行する代入になる。配列は要素ごとの store を並べ，書かれていない要素には
0 を書く。

宣言の処理で IR を出すことになるため，**関数の IR の初期化を仮引数と
局所宣言を読むより前へ移した**。第 2 部までは宣言に IR が関わらなかったので
本体に入る直前で初期化していた。

## 制限 (第 3 部の残りで解消する)

- 大域の初期化子に定数式 (`1 + 2`, `sizeof(int) * 3`) は書けない。
  式の評価器が IR を組み立てる作りのため，初期化子の文脈では使えない
- 構造体・共用体の初期化子は無い
- 入れ子の波括弧 (`int a[2][2] = {{1,2},{3,4}};`) は無い。
  多次元配列は平らに並べる形 (`{1,2,3,4}`) で書く
- 可変長引数・構造体の値渡しは無い
