# cc15l 説明文書

cc15l は C コンパイラの Stage 15 第 6 部の最初の世代である。
[cc15k.sc](cc15k.sc) を出発点に，**容量だけを広げた** (機能は同一。
前例: cc14f の IR 倍増，pp15)。tcc の翻訳単位 (ONE_SOURCE 前処理後
828 KB) は cc15k の器のほぼすべてを溢れさせる
([stage015-tcc.md](../docs/stage015-tcc.md) 12.5)。

ソース [cc15l.sc](cc15l.sc) が正本である。

## ビルド

```
sh tools/build.sh stage015
# cc15k(cc15l.sc) -> cc15l0     (1 段目)
# cc15l0(cc15l.sc) -> cc15l     (正本。以降は固定点)
```

SHA-256: c038fee9159633d666922175f0e2857a42fe9e0327929558ece69c5d5e41546a

- 対象: RV32IM，リトルエンディアン
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

## 広げたもの (実測値 → 新容量)

| 器 | cc15k | cc15l | tcc の実測 |
|---|---|---|---|
| 入力 src | 256 KiB **検査なし** | 4 MiB + 溢れ検査 | tcc.i は 828 KB |
| 出力 ob / ELF 組立て eb | 512 KiB / 1 MiB | 4 MiB / 8 MiB | |
| 名前スロット | 32 バイト | 64 バイト | 最長の識別子は 39 文字 |
| 大域記号 | 2048 | 8192 | 関数だけで約 1200 |
| 列挙定数 | 256 | 8192 | TOK_* 759 + DW_* 724 |
| 再配置 | 16384 | 262144 | |
| IR (関数あたり) | 16384 | 131072 | |
| typedef / 構造体 / メンバ | 256 / 256 / 2048 | 2048 / 2048 / 16384 | typedef 272 |
| 文字列リテラル | 255 バイト | 4095 バイト | ヘルプ文の連結で伸びる |

入力の読込みに**溢れ検査が無かった** (256 KiB を超えると隣の領域へ
書き続ける)。容量と同時に検査を足した (超過は器の掟どおり exit 6)。

名前スロットの拡幅に伴い，関数内 static の別名 (名前 + '.' + 通し番号)
の切詰めは 26 → 58 文字に広がる。

## 検証

- 固定点: cc15l(cc15l.sc) == cc15l0(cc15l.sc) (B2 == B3)
- 回帰: sh / ed / mk と rt64.c / rtfp.c の `.o` が変わらない
