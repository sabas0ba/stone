# cc15aa --- C コンパイラ 第 15 世代 その 27

`cc15z` との差は `next()` の 1 か所 1 行 (註を除く)。ソースは
`stage015/cc15aa.sc`。経緯は
[docs/stage017-gcc.md](../docs/stage017-gcc.md) 8.3 の 13。

**世代名が 2 文字になった最初の世代である** ([cc15z.md](cc15z.md) の
「世代名について」)。

## 直したもの: 小数点から始まる浮動小数点定数

C89 3.1.3.1 ——

> fractional-constant:
>   digit-sequence_opt `.` digit-sequence
>   digit-sequence `.`

**整数部は省ける。** `.0001` は妥当なリテラルである。`cc15z` までは
`next()` が

```c
  if (isdig(c)) return lexnum();
```

と**数字で始まるときしか**数として読まなかったので、`.` が演算子として
読まれて 1 (構文誤り) になった。

| 書き方 | `cc15z` | `cc15aa` |
|---|---|---|
| `0.5` | 通る | 通る |
| `1.` (小数部を省く) | 通る | 通る |
| `.0001` | **1 で拒む** | 通る |
| `.5e2` / `.5E-2` | **1 で拒む** | 通る |
| `v.m` (構造体の員) | 通る | 通る |
| `...` (可変長引数) | 通る | 通る |

## 直し方

`next()` に 1 行足す。**次が数字のときだけ**数として読む。

```c
  if (c == '.' && isdig(src[pos + 1])) return lexnum();
```

`lexnum()` はそのまま通せばよい —— 整数部を 0 桁読んでから `.` を見て
`lexfp()` へ渡すので、`0.0001` と同じ道になる。

**`.` は他にも使う。** 構造体の員 (`v.m`) と可変長引数の `...` が
あるので、`.` を無条件に数へ回してはいけない。1 文字先読みで分ける。

## 表に出た形

GCC 4.7.4 の `libcpp/symtab.c` の `approx_sqrt` ——

```c
  do
    {
      d = (s * s - x) / (2 * s);
      s -= d;
    }
  while (d > .0001);
```

`libcpp/symtab` 1 単位が止まっていた。**この単位は 3 つめの壁である** ——
[cc15w](cc15w.md) で仮引数並びの抽象宣言子を、[cc15x](cc15x.md) で
cast の型名を通した先にこれが出た。

## 鎖は変わらない

既存のソースにこの形は無い。`sh` / `ed` / `mk` を訳した `.o` は
`cc10l` のものと 1 バイトも変わらず、`cc15aa0` と `cc15aa` もバイト一致
する (`tests/stage015/test.sh` が両方を見る)。

## 測り方

- 台帳 `tests/stage015/ledger.txt` に `fpdot` を足した。**期待値は
  `y` ではなく 16 進の並びである** —— 整数部を 0 桁読んだ後の仮数と
  指数の組み立てが合っているかは、**ビットを見なければ判らない**。

  ```
  3f1a36e2eb1c432d:3fe0000000000000:4049000000000000:3fc0000000000000:y
  ```

  `.0001` / `.5` / `.5e2` / `.125` の 4 つを出す。あわせて
  `.0001 == 0.0001` (整数部の有無で値が変わらない)、`.5e2 == 50.0`、
  `.5E-2 == 0.005` を主張し、構造体の員と `...` を壊していないことも見る
- `tools/diff17.sh` がホストの `gcc` と突き合わせる。**ビット列まで
  一致する** —— `.0001` は 2 進で割り切れないので丸めが入るが、
  ホストと同じ `3f1a36e2eb1c432d` になる
