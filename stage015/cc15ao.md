経緯は [docs/stage017-gcc.md](../docs/stage017-gcc.md) 8.15。

## 直したもの: alloca の領域を呼んだ関数の戻りで返す

我々の cc は関数の枠の大きさを翻訳時に決めるので，alloca はスタックを伸ばせない。libc26 の第 1 版の alloca はヒープから取り，次に呼ばれたとき「今より深い所で取った分」を返していた。**同じ深さで繰り返し呼ばれる関数 (ループの中から呼ぶ関数) の分は返らない。** 返るのは，より浅い所から alloca が呼ばれたときである (自動レビューの指摘)。GCC は `XALLOCAVEC` などで alloca を多用するので，長い翻訳ではヒープが尽きうる。

寿命は「呼んだ関数が戻るまで」である。cc が 2 つを行う。

1. `alloca(n)` の呼出しを `__alloca2(n, fp)` に書き換える。fp は呼んだ関数の枠の基底 (x8) である。
   - alloca 自身の枠の位置で深さを測ってはいけない。その枠は，alloca が戻った後に同じ関数から呼ぶ別の関数の枠と重なる。浅い関数が取った領域を，深い関数の戻りで返してしまう。
2. alloca を呼んだ関数は，戻る直前 (`epilog2()`) に `__alloca_release(fp)` を呼ぶ。libc は基底が fp 以下 (この呼出しと，より深い呼出し) の領域を返す。
   - 戻り値はその前にデータスタックへ積んである。呼出しで ra とレジスタが壊れても，`epilog2()` が後で戻す。

書き換えるのは名前が `alloca` の大域関数への直接の呼出しだけである。関数へのポインタを通した呼出しは libc26 の `alloca` (第 1 版と同じ振舞い) へ行く。

## 直したもの 2: C99 の宣言の置き場

GCC の前提の GMP 6.3 は C99 で書かれた単位を持つ。

| 書き方 | 単位 |
|---|---|
| 文の後の宣言 (C99 6.8.2) | mpn/get_str・mpn/set_str・mpn/gcd_22・mpz/stronglucas・mpz/oddfac_1 |
| for の初期化節の宣言 (C99 6.8.5.3) | primesieve・mpz/nextprime・mpz/millerrabin・mpz/primorial_ui・mpn/compute_powtab |

- 複文と関数本体で，文の後にも宣言を置ける。名前は宣言した所から複文の終わりまで見える。
- for の初期化節に宣言を置ける。名前の有効範囲は for 文の終わりまでで，複文と同じく入口で名前の数とフレームの位置を控え，出口で戻す。

古い GMP (C89 で書かれた版) へ差し替える手もあった。最終目標の gcc・Linux のビルドでは C99 以降の書き方が要るので，我々のコンパイラで受ける。

## 直したもの 3: 記憶域クラスの前の型修飾子

宣言の指定子の順は自由である (C89 6.5)。GMP の mpq/cmp.c が `const static mp_limb_t one = 1;` と書く。`cc15an` までは記憶域クラスを先頭でだけ読んでいたので，const の後の static で 1 になっていた。局所と大域の両方で受ける。

## 直したもの 4: 関数内 static の初期化子のアドレス定数

同じ mpq/cmp.c が続けて `const static mpz_t den = {{0, (1), ((mp_limb_t *) &one)}};` と書く。

- 二重の括弧: ポインタの欄の括弧は値を変えないので，括弧の中を初期化子として読む。整数の欄は括弧つきの定数式なので従来どおり畳み込む。
- `&one` の `one` は同じ関数の static で，大域の表には別の名前で入っている。関数内 static の初期化子では局所の表を先に引く (`ginitsym()`)。

## ビルドチェーンは変わらない

既存のソースは alloca を呼ばず，C99 の宣言と上の書き方を使わないので，`sh` / `ed` / `mk` を訳した `.o` は `cc10l` のものと 1 バイトも変わらない。

## 測り方

`tests/stage017` 第 12 部 (`tests/stage017/user/l26x.c`) が，同じ深さで alloca を呼ぶ関数を 10 万回呼ぶ。1 回 4000 バイトなので，戻りで返さなければ 400 MB を取ろうとしてヒープ (プロセスの領域は 256 MiB) が尽きる。

| | `cc15an` | `cc15ao` |
|---|---|---|
| `l26x` の 10 万回の alloca | **abort (134)** | 通る |
| `tools/diff17.sh c99decl` | **我々だけが拒む** | 値が一致 |
| `tools/diff17.sh initaddr` (関数内 static) | **我々だけが拒む** | 値が一致 |

`tests/stage015/probe/c99decl.c` は for の変数と外側の同名の変数，文の後の宣言の初期化の順，`const static` を値で見る。
