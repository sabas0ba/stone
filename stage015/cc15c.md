# cc15c 説明文書

cc15c は C コンパイラの Stage 15 第 2 部の世代である。
[cc15b.sc](cc15b.sc) (64 bit の演算) を出発点に，**64 bit の実引数**を
通した。設計は [stage015-tcc.md](../docs/stage015-tcc.md) 6.2 の項目 11。

ソース [cc15c.sc](cc15c.sc) が正本である。

## ビルド

```
sh tools/build.sh stage015
# cc15b(cc15c.sc) -> cc15c0     (1 段目)
# cc15c0(cc15c.sc) -> cc15c     (正本。以降は固定点)
```

SHA-256: e9e78385f8c65c00d231636f2dae939872fa1e87f9199026803cacf48498e904

- 対象: RV32IM，リトルエンディアン，175152 バイト
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

## この世代で通るようになったもの

**64 bit の実引数。** 前後に 32 bit の引数を置いても，それぞれ正しく
渡る。

引数の受渡しは元から**語数**で数えていた (構造体が複数語を占めるため)。
`nwords` が 64 bit に 2 を返すようにするだけで，**呼ばれた側のフレーム
配置は何も変えずに済んだ**。積む順は下位語・上位語で，これは記憶域の
並び (下位語が低い方) と一致する。

## この世代がまだ拒むもの (終了コード 5)

- **64 bit の返却** (項目 11 の残り)
- 乗算・除算・剰余 (項目 8・9)
- 可変長引数の可変部に置く 64 bit (語数と個数がずれると並べ替えられない)
- 64 bit とポインタの加減算
