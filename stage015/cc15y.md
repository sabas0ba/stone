# cc15y --- C コンパイラ 第 15 世代 その 25

`cc15x` との差は `econd()` の 1 か所 2 行 (註を除く)。ソースは
`stage015/cc15y.sc`。経緯は
[docs/stage017-gcc.md](../docs/stage017-gcc.md) 8.3 の 12。

## 直したもの: 条件演算子の型は順序に依存しない

C89 6.3.15 ——

> 一方の被演算子が空ポインタ定数であれば、結果は他方の型を持つ。

`cc15x` までは結果の型を**then 側からだけ**取っていた。

```c
  // 結果の型は then 側とする
  ety = t;
```

したがって

```c
(k ? 0 : p)->f
```

の型が `int` になり、`->` が型の誤り (5) になる。

| 書き方 | `cc15x` | `cc15y` |
|---|---|---|
| `(k ? 0 : p)->f` | **5 で拒む** | 通る |
| `(k ? p : 0)->f` | 通る | 通る |
| `(k ? (struct m *)0 : p)->f` | 通る | 通る |
| `(k ? 1 : p)->f` (0 でない整数) | 5 で拒む | **5 で拒むまま** |
| `(k ? 1 : 2) + 1` | 通る | 通る |

**片方の並びだけが動いていた。** `(k ? p : 0)` は then 側がポインタ
なので、誤った規則のままたまたま正しい型になっていた。

**代入や返却では表に出ない。** そちらは左辺の型へ変換する道を通るので、
条件式の型が誤っていても結果が合う。`->` を直に当てて初めて出る。
`cc15u` (複合代入の符号) と同じで、**黙って違うものを作っていた**族で
ある —— ただしこちらは値ではなく型なので、拒む形で表に出た。

## 表に出た形

GCC 4.7.4 の `include/line-map.h` 518 行 ——

```c
#define INCLUDED_FROM(SET, MAP)						\
  ((linemap_check_ordinary (MAP)->d.ordinary.included_from == -1)	\
   ? NULL								\
   : (&LINEMAPS_ORDINARY_MAPS (SET)[(MAP)->d.ordinary.included_from]))
```

を `line-map.c` 266 行がそのまま `->` で辿る。我々の `NULL` は
`stage017/libc21/include/stddef.h` 21 行の `0` なので、then 側は
**整数定数 0** である。`libcpp/line-map` 1 単位が止まっていた。

## 直し方

空ポインタ定数かどうかは IR で見る —— then 側の値が定数 0 の命令で
あればよい。

```c
  if ((t >> 16) == 0 && (ety >> 16) != 0
      && iop[a] == c_const && ia[a] == 0) t = ety;
```

- `(t >> 16) == 0` —— then 側がポインタでない
- `(ety >> 16) != 0` —— else 側がポインタである
- `iop[a] == c_const && ia[a] == 0` —— then 側の値が定数 0

`(void *)0` は既にポインタ型なのでここへは来ない。逆向き (then が
ポインタ・else が 0) は then 側を採るのがそのまま正しいので何もしない。

## 限界

**畳んだ定数式は見ない。** `(k ? 1 - 1 : p)->f` の `1 - 1` は
`c_bin + b_sub` のままなので、`iop[a] == c_const` に当たらず拒む。
C89 は「値 0 の整数定数式」を空ポインタ定数と呼ぶので、厳密にはここも
受けるべきである。GCC 4.7.4 の libiberty / libcpp の閉包に現れる形は
`NULL` (= `0`) だけなので、**会ってから足す**。

## 鎖は変わらない

既存のソースにこの形は無い。`sh` / `ed` / `mk` を訳した `.o` は
`cc10l` のものと 1 バイトも変わらず、`cc15y0` と `cc15y` もバイト一致
する (`tests/stage015/test.sh` が両方を見る)。

## 測り方

- 台帳 `tests/stage015/ledger.txt` に `condnull` を `ok y\n` で足した。
  **型だけ通しても指す先が違えば意味がない**ので、`line-map.h` と同じ形
  (`-1` なら空、そうでなければ表の要素) を作り、**添字を変えれば指す先も
  変わる**ことまで見る。`(k ? p : 0)` の道と、代入で受ける道と、
  整数どうしの条件式も一緒に通して壊していないことを見る
- `tools/diff17.sh` がホストの `gcc` と突き合わせる。ホストも
  `-std=c89 -pedantic-errors` で通し、同じ `y` を出す
