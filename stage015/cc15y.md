# cc15y --- C コンパイラ 第 15 世代 その 25

`cc15x` との差は 2 か所で，どちらも **GNU の文式** (`({ 文...; 式; })`)
である。ソースは `stage015/cc15y.sc`。設計は
[docs/stage018-ext.md](../docs/stage018-ext.md) 7。

```c
#define MAX(a, b) ({ int _a = (a); int _b = (b); _a > _b ? _a : _b; })
```

## 1. なぜ要るか

GCC とカーネルのヘッダは，引数を 1 度だけ評価する `max` / `min` を
この形で書く。**マクロなので，呼ぶ側のソースを直しても避けられない。**

## 2. どう直したか

一次式の `(` を読んだ直後が `{` なら文式である。見分けはその 1 文字
だけで済む —— キャストは `(` の次が型名なので既に別の道へ入っている。

中身は複文とほぼ同じ環である。違いは 2 つ。

- **式文の値を控える。** 文の環を回しながら，式文に当たるたびに値と
  型を覚え，`}` に来た時点の最後のものを返す
- **右辺値にしてから控える。** 左辺値のまま返すと，呼び手はアドレスを
  値として使う

名前の見える範囲は複文と同じで，`lcnt` / `cloff` / `lblk` を退避して
戻す。

## 3. 文と式の見分け

環の中では「宣言・文・式文」の 3 通りが来る。宣言は `istype()`，文は
先頭のトークン (`if` / `while` / `for` / `do` / `switch` / `case` /
`default` / `break` / `continue` / `goto` / `return` / `{` / `;`) で
見分ける。**ラベル (`名前 :`) だけは 1 つ先を見ないと式と区別が
つかない** —— `stmt()` が使っているのと同じ手を使う。

## 4. 受けないもの

**最後が式文でない文式は拒む** (`exit(5)`)。GNU C は「その場合の値は
void」と定めるが，我々がここへ来るのは値の要る場所だけなので，黙って
前の式の値を返すより拒むほうがよい。

## 5. 鎖は変わらない

既存のソースはこの形を使っていない。`sh` / `ed` / `mk` の `.o` は
`cc10l` のものと一致し，`cc15y0` と `cc15y` もバイト一致する。
