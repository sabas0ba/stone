`cc15t` との差は `assign()` の 1 か所 3 行 (註を除く)。ソースは
`stage015/cc15u.sc`。経緯は
[docs/stage017-gcc.md](../docs/stage017-gcc.md) 5.1。

## 直したもの: 複合代入が符号を見ていなかった

`a op= b` は `a = a op b` と同じ意味である (C89 6.3.16.2)。除算・
剰余・右シフトは**符号で機械語が変わる** (`div`/`divu`・`rem`/`remu`・
`sra`/`srl`) ので，複合代入も二項演算と同じ規則で選ばなければならない。

複合代入のトークンは `o_asnb + b_*` に並べてある。`o_asnb` を引けば
二項演算の種別になるが，**その並びは符号つき側**である
(`b_div` / `b_rem` / `b_srl`)。`assign()` はそれをそのまま
`emit(c_bin + op, ...)` に渡していた。

```c
unsigned int a;  a %= 65521;   /* 符号つき剰余 (rem) になっていた */
int a;           a >>= 1;      /* 論理シフト (srl) になっていた */
```

二項の道 (`b = a % c` / `b = a >> c`) は `isuar()` を見て
`b_urem` / `b_sra` を選んでいた。**片方だけ直っている**状態が
Stage 10 から残っていたことになる。

```c
if (op == b_div) { if (isuar(t) || isuar(ety)) op = b_udiv; }
else if (op == b_rem) { if (isuar(t) || isuar(ety)) op = b_urem; }
else if (op == b_srl) { if (!isuar(t)) op = b_sra; }
```

条件は二項の道と**同じ形**にしてある —— 除算・剰余は左右どちらかが
符号なしなら符号なし (通常の算術変換)，右シフトは左辺の符号で決まる。

## 見つかり方: zlib の adler32 が誤った値を返した

[docs/stage017-gcc.md](../docs/stage017-gcc.md) 5.1 の測定である。
`zlib` を我々の器で組んで我々の OS の上で走らせ，**ホストの GCC で
同じソース・同じ駆動を組んだものと値を突き合わせた**。

```
        crc32     adler32     level 1/5/9 の長さ
我々    282d245a  43dc7153    3042 / 1537 / 1537
ホスト  282d245a  459e7153    3042 / 1537 / 1537
```

`crc32` も圧縮長も一致するのに **`adler32` だけ違う**。しかも
**下位 16 bit (`7153`) は合っていて上位 16 bit だけが違う**。

adler32 は 2 つの和を持つ。下位 `adler` は最大でも約 142 万，上位
`sum2` は約 39 億 —— **`sum2` だけが 2^31 を超える**。

```c
#define MOD(a) a %= BASE        /* adler32.c 55 行 */
```

符号つき剰余だと `sum2` が負の数として扱われ，値が違う。
「下位だけ合う」という出方が，そのまま原因を指していた。

## 鎖は変わらない

**我々のソースは `>>=` / `/=` / `%=` を 1 つも使っていない。**
`sh` / `ed` / `mk` を訳した `.o` は `cc10l` のものと 1 バイトも
変わらず，`cc15u0` と `cc15u` もバイト一致する。

つまりこれは，**自分自身を組む限り永久に表に出ない誤り**だった。
外のソースを的として読ませなければ見つからない類である。

## 測り方

台帳 `tests/stage015/ledger.txt` の `asnsign`。
プローブ `tests/stage015/probe/asnsign.c` が見るもの ——

- 符号なしの `%=` / `/=` を **2^31 を超える値**で (ここが分かれ目)
- 二項の道と同じ値になること (前から合っていた側を壊さない)
- 符号つきの `>>=` を**負の値**で (`-256 >>= 4` が `-16`)
- 符号なしの `>>=` は論理シフトのまま
- 壊していないこと —— `<<=` `*=` `+=` `-=` `&=` `|=` `^=`，
  符号つきの `/=` `%=` が 0 方向へ丸めること
- **adler32 の形そのもの** —— 5552 回足して `sum2` が 2^31 を超えた
  ところで `%= 65521`

`cc15t` はこのプローブで `n` を返す。
