# cc15i 説明文書

cc15i は C コンパイラの Stage 15 第 3 部の 4 番目の世代である。
[cc15h.sc](cc15h.sc) を出発点に，**浮動小数点の四則・比較・条件**を
入れた。設計は [stage015-tcc.md](../docs/stage015-tcc.md) 10 章。

ソース [cc15i.sc](cc15i.sc) が正本である。

## ビルド

```
sh tools/build.sh stage015
# cc15h(cc15i.sc) -> cc15i0     (1 段目)
# cc15i0(cc15i.sc) -> cc15i     (正本。以降は固定点)
```

SHA-256: d5f63e893cb5710804d1dfd29e17c026bc140f58c9937a96f5c138ba5dbb7cd4

- 対象: RV32IM，リトルエンディアン
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

## 形

すべて**実行時支援 ([rtfp.c](rtfp.c)) の呼出し**に落とす。IR に命令
種別を足していない。呼出しの規約は 64 bit の除算 (`ll_call2`) と同じ。

- **四則** (`+ - * /`): 両辺を double へ持ち上げ (`fplift`)，`__dadd` /
  `__dsub` / `__dmul` / `__ddiv` を呼ぶ。`%` は C の規則どおり拒む
- **結果の型**は C の通常の算術変換 (どちらかが double なら double，
  そうでなければ float)。float の結果は最後に 1 回だけ `__d2f` で丸め
  直す。**計算を double で行っても加減乗除では結果が変わらない**
  (double の仮数は float の 2 倍 + 2 以上あるという既知の性質)
- **比較** (`< > <= >= == !=`): `__dcmp` が -1 / 0 / 1 / 2 (2 = NaN)
  を返し，それを突き合わせる。NaN はすべての比較が偽で `!=` だけ真に
  なる。値の突き合わせで自然にそうなる (`fpcmpres`)
- **条件** (`if (d)` など): `__dcmp(d, +0.0) != 0` に落とす。
  **-0.0 が偽**になり (or では書けない理由)，**NaN は真**になる

## まだ無いもの (拒む。台帳 fparg)

仮引数と実引数の浮動小数点。記号表が仮引数の型を持たないので，実引数を
変換すべきか判らない (64 bit 整数のビット表 gllm と同じ形の拡張が要る)。
複合代入・++/-- ・?: の浮動小数点も引き続き拒む。

## 検証

- 固定点: cc15i(cc15i.sc) == cc15i0(cc15i.sc) (B2 == B3)
- 回帰: sh / ed / mk と rt64.c / rtfp.c の `.o` が 1 バイトも変わらない
- 台帳: fparith (四則・比較・NaN・-0.0 の 12 まとまり) ok。
  fpstore と合わせ 13 件 ok / 1 件 gap / 0 件 bad
