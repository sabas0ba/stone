# cc15w --- C コンパイラ 第 15 世代 その 23

`cc15v` との差は `fnpdec()` と `pparam()` の 2 か所 (註を除く)。ソースは
`stage015/cc15w.sc`。経緯は
[docs/stage017-gcc.md](../docs/stage017-gcc.md) 8.3 の 4。

## 直したもの: 仮引数並びの括弧付き抽象宣言子

C89 6.5.4 ——

> 抽象宣言子とは，識別子を含まない宣言子である。

プロトタイプでは仮引数の名前を省ける。関数ポインタも例外ではなく

```c
extern int g(int (*)(int));
```

は妥当な宣言である。`cc15v` までは仮引数の関数ポインタの宣言子を
`( * 名前 ) ( 仮引数 )` の形でしか読まず、名前の位置に `)` が来ると
1 (構文誤り) で止まっていた。

| 書き方 | `cc15v` | `cc15w` |
|---|---|---|
| `int g(int (*f)(int));` (名前つき) | 通る | 通る |
| `int g(int (*)(int));` (抽象宣言子) | **1 で拒む** | 通る |
| `int (*)(int);` (大域。宣言子として意味を持たない) | 1 で拒む | **1 で拒むまま** |

**欠けていたのは抽象宣言子の側だけ**である。名前を書けば通っていた。

## 表に出た形

GCC 4.7.4 の `include/obstack.h` 193 行 ——

```c
extern int _obstack_begin (struct obstack *, int, int,
			   void *(*) (long), void (*) (void *));
```

を libcpp の全単位が `include/symtab.h` 22 行経由で読む。
`tools/gcc17.sh where` は、この形で止まる 10 単位のどれでも `.i` の
**同じ 1843〜1989 行**を指した。`libiberty/obstack` と
`libcpp/symtab` を合わせて **12 単位**がここで止まっていた。

`pp18` で前処理を OS 側へ移すまで、この 10 単位は前処理の段
(`ppext`) で止まっていて**この壁は見えていなかった**
([docs/stage017-gcc.md](../docs/stage017-gcc.md) 8.2)。1 つ通すと次が
見える。

## 直し方

`fnpdec()` を `fnpdec1(b, anon)` に割り、`anon` が 1 のときだけ名前の
省略を受ける。名前を省いたときは `fpnam` を空にする。

```c
  fpnam[0] = 0;
  if (tok == t_id) {
    copyn(fpnam, tname);
    next();
  } else if (anon == 0) {
    exit(1);
  }
```

`fnpdec(b)` は `fnpdec1(b, 0)` の別名として残す。**呼ぶ側 5 か所のうち
仮引数並び (`pparam`) だけ**が `fnpdec1(b, 1)` を使う。他の 4 か所
(大域・局所・構造体の員・K&R の型宣言) では名前の無い宣言子は宣言として
意味を持たないので、受けてしまうと記号の無い宣言が通る。

`pparam()` は名前が空なら記号を作らず、占める語だけ数えて返る。

```c
    if (fpnam[0] == 0) {
      cna = cna + 1;
      return 0;
    }
```

## 限界

`( * ) ( 仮引数 )` だけを受ける。**括弧付きの抽象宣言子一般ではない。**

| 形 | `cc15w` |
|---|---|
| `int g(int (*)(int));` | 通る |
| `int g(int (*));` (括弧で括っただけのポインタ) | 1 で拒む |
| `int g(int (*)[4]);` (配列へのポインタ) | 1 で拒む |

どちらも C89 として妥当だが、GCC 4.7.4 の libiberty / libcpp の閉包には
現れない。**会った形だけを足す** —— 会っていない形を想像で足すと、
根拠の無い実装が残る (`cofs` の `sizeof` を保留したのと同じ判断)。

## 鎖は変わらない

既存のソースはプロトタイプで関数ポインタの仮引数名を省いていない。
`sh` / `ed` / `mk` を訳した `.o` は `cc10l` のものと 1 バイトも変わらず、
`cc15w0` と `cc15w` もバイト一致する (`tests/stage015/test.sh` が両方を
見る)。

## 測り方

- 台帳 `tests/stage015/ledger.txt` に `fnpabs` を `ok y\n` で足した。
  **読めるだけでは足りない**ので、抽象宣言子で宣言した関数を名前つきで
  定義し、**実際に呼んで値を見る** —— 仮引数の位置がずれていれば値が
  違う。先頭・末尾・中間、関数ポインタ 2 つ、返却型がポインタの形、
  そして `obstack.h` 193 行と同じ並び (スカラ 2 つを挟んで関数
  ポインタ 2 つ) を通す
- `tools/diff17.sh` がホストの `gcc` と突き合わせる。ホストも
  `-std=c89 -pedantic-errors` で通し、同じ `y` を出す
