# ld12 説明文書

ld12 は実行像を作るリンカの Stage 12 世代である。stage008 の
[ld.sc](../stage008/ld.sc) を出発点に，**カーネル ('K') と ELF 実行形式
('E') の出力**を足した。設計は
[stage012-os.md](../docs/stage012-os.md) 5.3。

ソース [ld12.sc](ld12.sc) が正本である。バイナリはビルドで再現される
生成物であり，git 管理しない。

## ビルド

```
sh tools/build.sh stage012
# cc(ld12.sc) -> ld12.o -> ld(stage008) -> ld12.bin
```

SHA-256: 5ad5907018e04d684f0d3a28741d10570a43bc7d8c4b013dce35027aa8302a07

- 対象: RV32IM，リトルエンディアン，33860 バイト
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

## 出力形式は入力の先頭 1 バイトで選ぶ

| 形式 | 前置部 | 出力 | ロードアドレス |
|---|---|---|---|
| `'F'` | 従来と同一 (stage008 から一字一句変えていない) | フラット | 0x8000_0000 |
| `'K'` | カーネル前置部 (PMP・mtvec・trap 入口・urun) | フラット | 0x8000_0000 |
| `'E'` | ユーザ前置部 (argc/argv・syscall スタブ) | ELF 実行形式 | 0x8600_0000 |

```
{ printf 'K'; cat kernel.o; printf '\0'; } | ld12 > kernel.bin
{ printf 'E'; cat prog.o;   printf '\0'; } | ld12 > prog
```

`'F'` の出力が stage008 の ld とバイト一致することを
[../tests/stage012/test.sh](../tests/stage012/test.sh) が確認する
(pp / cc10l / ld の 3 つのオブジェクトで照合)。既存 Stage は従来どおり
stage008 の ld を使い続けるので，各 `.md` の SHA-256 は変わらない。

## 前置部が提供するシンボル

| 形式 | シンボル |
|---|---|
| `'F'` | getc, putc, exit |
| `'K'` | getc, putc, exit, urun |
| `'E'` | getc, putc, exit, read, write, openat, close, brk |

`'K'` は加えて，カーネルが定義する `ktrap` への呼出しを trap 入口へ
埋める (`main` と同じ後埋め)。

## 特権命令を前置部に閉じ込める

カーネルが要る PMP 設定・mtvec 設定・レジスタ退避・mret は C では書けない。
これらはすべて前置部が機械語で持ち，**cc には手を入れていない**
([stage012-os.md](../docs/stage012-os.md) 5.2)。ベアメタルの getc/putc/exit を
前置部が持つのと同じ形である。
