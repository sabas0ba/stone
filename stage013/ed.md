# ed 説明文書

ed は行エディタである。OS (kernel13) の上で動く ELF 実行形式のユーザ
プログラムで，端末の能力を何も仮定しない (画面制御を使わない) ため
UART の素の文字流の上でそのまま動く。設計は
[stage013-tools.md](../docs/stage013-tools.md) 5 章。

ソース [ed.c](ed.c) が正本である。自作の C89 + 第 13 世代の libc
([libc/](libc/)) で書かれている。バイナリはビルドで再現される生成物で
あり，git 管理しない。

## ビルド

```
sh tools/build.sh stage013
# bundle(include/*.h ed.c) | pp | cc -> ed13.o
# ld13 'E' (ed13.o + string + stdlib + sys + morecore + stdio) -> ed13
```

SHA-256: f03f51695dd058f2e30c74d363dc16bbe80b225de2af3370300943071322619f

- 形式: ELF 実行形式 (RV32, ET_EXEC)，39316 バイト
- ロードアドレス: 0x8600_0000 (カーネルが配置する)

## 使い方

```
ed [ファイル名]
```

引数を与えると読み込み，バイト数を出す。

### アドレス

`.` (現在行)，`$` (最終行)，数，およびそれらに続く `+N` / `-N`
(N の既定は 1)。範囲は `a,b`，`,` だけなら `1,$`。省略時は現在行。

### コマンド

| コマンド | 内容 |
|---|---|
| (アドレスのみ) | その行へ移り，出す。空行なら次の行 |
| `a` | アドレスの後ろへ追加。`.` だけの行で終える |
| `i` | アドレスの前へ挿入 |
| `c` | アドレスの範囲を置き換える |
| `d` | 消す |
| `p` | 出す |
| `n` | 行番号を付けて出す |
| `=` | 行番号を出す (アドレス省略時は最終行) |
| `s/古/新/[g]` | 置換。`g` で行内のすべて |
| `w [名前]` | 書き出してバイト数を出す。省略時は開いた名前 |
| `r [名前]` | 読み込み，アドレスの後ろへ入れる |
| `q` | 終える。未書き出しの変更があると 1 度だけ拒む |
| `Q` | 変更があっても終える |

- 誤りはすべて `?` の 1 行で表す (ed の作法)。理由は出さない
- 入力の終わり (EOT または EOF) は，コマンド待ち・入力モードのどちらでも終了

## 制限

- **`s` は正規表現ではなく，文字列そのままの一致である**
  ([stage013-tools.md](../docs/stage013-tools.md) 5.3)。区切りは `s` の
  次の 1 文字なので，`/` を含む文字列は `s,古,新,` のように書ける
- 1 行は 511 バイトまで，全体は 4096 行まで
- `g` (大域コマンド)・`m` (移動)・`t` (複写)・undo は持たない
