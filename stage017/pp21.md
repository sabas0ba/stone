# pp21 説明文書

pp21 は C プリプロセッサの第 21 世代である。[pp20.sc](pp20.sc) の**全文複製**に，**指令行の器の大きさ**だけを変えた。展開の規則も，`-I` の探し方も，出力も変えていない。

ソース [pp21.sc](pp21.sc) が原本である。

## ビルド

```
sh tools/build.sh stage017
# cc15p(pp21.sc) -> pp21.o -> ld16 'E' -> pp21
```

SHA-256: d30a36eb83429298c93e27a4f8b22fb953bd67ab43e2bbfae1e0cad566750633

## なぜ要ったか

GCC の前提の MPFR 3.1.6 を `pp20` に通すと，**ほぼ全単位が容量超過 (6) で止まった** ([docs/stage017-gcc.md](../docs/stage017-gcc.md) 8.15)。

`mpfr-impl.h` は `MPFR_RNDRAW_GEN` という 119 行・9218 バイトのマクロを持つ。行を継いだ (`\` で終わる) 指令は 1 行として指令行の器 (`dbuf`) に入るので，器の 8 KiB を越えていた。`mpfr-impl.h` は MPFR のほぼ全単位が読む。

| | `pp20` | `pp21` |
|---|---|---|
| 指令行の器 | 8 KiB | 64 KiB |

マクロ本体の器は 4 MiB あり (`pp20` で広げた)，9 KB の本体は収まる。

## 測り方

`tools/gcc17.sh unit mpfr/add` は `pp20` で `cap pp 6`，`pp21` で `ok` になる。gcc/ の単位の `.i` は `pp20` と同じである (指令行が 8 KiB を超える単位は gcc/ に無い)。
