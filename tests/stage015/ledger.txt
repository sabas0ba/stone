# ---- 静的な初期化子の中の文字列リテラル (cc15q / cc15s で直した) ----
#
# Stage 14 の台帳には cc14g で測った bad が載っている。あちらは
# その世代の記録なので据え置き，こちらが最前線の姿である。
#
# staticstr  … cc15q で直した形 (関数内 static のポインタ・構造体の中の
#               char 配列・大域の static)
# staticstr2 … cc15s で直した形 (多次元の char 配列)。**族を 16 の形で
#               まとめて測る** —— 畳む道と，直しで壊していないことも
#               含めて見る。1 つの形で確かめて族ぜんぶが無事だと思った
#               のが 3 度の誤りの元だった (docs/stage017-cc.md 27.4)
#
# **行は分けたままにする。** 1 行にまとめると，どちらかが bad へ戻った
# ときにどちらか判らなくなる
staticstr    ok   y\n
staticstr2   ok   y\n
