# cc 説明文書

cc は C サブセット言語 sc のソースを **ELF リロケータブルオブジェクト** へ
変換するコンパイラである。設計は [stage008-elf-ld.md](../docs/stage008-elf-ld.md)，
言語仕様は [stage005-sc.md](../docs/stage005-sc.md) 2 章 (変更なし) を参照。

Stage 7 の occ から，字句解析・構文解析・IR・最適化・レジスタ割付けをそのまま
引き継ぎ，出力のみを実行可能なフラットバイナリから ELF ET_REL へ変えたものである。
生成物を実行するにはリンカ ([ld.md](ld.md)) が必要になる。

ソース [cc.sc](cc.sc) が正本である。バイナリはビルドで再現される生成物であり，
git 管理しない。

生成物を `cc8.bin` と呼ぶのは，Stage 10 で後継の C コンパイラが出てくる
ためである。`cc.bin` は常に最新世代を指し，過去世代は世代番号を付けて呼ぶ
([stage010-c89.md](../docs/stage010-c89.md) 2.1)。ソースと SHA-256 は
改称の前後で変わらない。

## ビルド

```
sh tools/build.sh stage008
# ... -> occ -> cc0 (ブートストラップ) -> cc8.o -> cc8.bin
```

occ はフラットバイナリを出力するので `cc.sc` を単体で実行形式にでき，
それが `cc0` になる。以降は `cc0` が出力したオブジェクトを `ld0` がリンクして
正本 `cc8.bin` を得る。

SHA-256: 3a5ae4c010ff1429da6f49fa97eb26edec32054acd6d19633d9788b5dcc9607a

- 対象: RV32IM，リトルエンディアン，76828 バイト
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

## occ からの変更点

| 箇所 | 変更 |
|---|---|
| 大域変数 | 絶対アドレスを埋めず，`.bss` 内オフセットを割り当てる。参照は `lui`+`addi` と HI20/LO12_I 再配置 |
| 関数呼出し | 常に変位 0 の `jal` を出し，JAL 再配置を付ける。自オブジェクト内の呼出しもリンカに委ねる |
| 文字列リテラル | `.text` 内に置き，無名のローカルシンボル (`.LCn`) を立てて再配置を張る |
| ランタイム前置部 | 出力しない。リンカの持ち物になった |
| `getc`/`putc`/`exit` | 固定アドレスではなく未定義シンボルとして扱う |
| 未定義シンボルの検査 | 行わない (リンカの仕事) |

## 追加された部分

| 関数 | 内容 |
|---|---|
| `addrel` / `esymaddr` | 再配置の記録と，シンボルアドレスの `lui`+`addi` 展開 |
| `ew1` / `ew2` / `ew4` | ELF ファイルへのバイト・16 bit・32 bit 書込み |
| `stadd` / `stadd_lc` | `.strtab` への名前追加 (`.LCn` は数値を手で文字列化する) |
| `esym` / `eshdr` | シンボル表エントリとセクションヘッダの出力 |
| `elfsym` | 内部のシンボル符号化から ELF シンボル番号への変換 |
| `writeelf` | セクション配置の計算と ELF ファイル全体の組立て |
