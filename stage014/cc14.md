# cc14a 説明文書

cc14a は C コンパイラの Stage 14 世代である。stage010 の
[cc12.sc](../stage010/cc12.sc) を出発点に，適合台帳
([../tests/stage014/ledger.txt](../tests/stage014/ledger.txt)) の
未対応を潰した。設計は
[stage014-external.md](../docs/stage014-external.md) 5 章。

ソース [cc14.sc](cc14.sc) が正本である。バイナリはビルドで再現される
生成物であり，git 管理しない。

## ビルド

```
sh tools/build.sh stage014
# cc10l(cc14.sc) -> cc14a0        (1 段目)
# cc14a0(cc14.sc) -> cc14a        (正本。以降は固定点)
```

SHA-256: d56f7c4f6dff376fd726bd8203aea127c89ff1acaed916f880ef8cd954a96196

- 対象: RV32IM，リトルエンディアン，140532 バイト
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

前段の成果物のみでビルドするという約束のとおり，1 段目は cc10l
(= `cc.bin`) が作る。正本はその 1 段目が自分自身を再コンパイルしたもので，
以降は固定点になる (B2 == B3)。

## cc10l との差分

| 足したもの | 台帳の項目 |
|---|---|
| 1 つの宣言に複数の宣言子 (`int a, *p, v[4];`) | multidecl |
| 隣接する文字列リテラルの連結 (`"ab" "cd"`) | strcat_lit |
| 整数定数の接尾辞 (`U` / `L`) | usuffix |
| `register` / `auto` 記憶域クラス | registerkw |
| `long long` を **拒む** (通して 32 bit にしない) | llwidth |

いずれも構文と字句の幅であり，**コード生成には触れていない**。

## cc.bin は差し替えない

`cc.bin` は Stage 10 の最終世代 (cc10l) を指したままにしてある。
最新世代へ向けると Stage 11 以降の記録済み成果物がすべて別のバイト列に
なるためである (それらは cc10l が作ったものとして凍結されている。
[artifacts.md](../docs/artifacts.md))。世代を足す段では別名で置き，
差し替えは必要になった時点で判断する。

## 残っている未対応

台帳を参照。入れ子の初期化子・関数名の初期化子・関数内 `static`・
K&R 形式の関数定義・ビットフィールド・不完全型への `typedef` 前方参照・
浮動小数点・空の引数リストへの実引数が残っている。

`long long` は「拒む」に変えただけで，64 bit 整数そのものは無い。
