# cc14e 説明文書

cc14e は C コンパイラの Stage 14 第 6 部の世代である。
[cc14d.sc](cc14d.sc) (第 5 部) を出発点に，**ビットフィールド**を足した。
設計は [stage014-external.md](../docs/stage014-external.md) 9 章。

ソース [cc14e.sc](cc14e.sc) が正本である。

## ビルド

```
sh tools/build.sh stage014
# cc14d(cc14e.sc) -> cc14e0     (1 段目)
# cc14e0(cc14e.sc) -> cc14e     (正本。以降は固定点)
```

SHA-256: 98a2776761e91c1c6356625c61ef476e6028e40fa215a318d634ab2a7216da74

- 対象: RV32IM，リトルエンディアン，149512 バイト
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

## cc14d との差分 (台帳: bitfield)

`struct f { unsigned a : 3; unsigned b : 5; };` が通る。

### 配置

- 語 (32 bit) の中へ**下位ビットから**詰める。連続するビットフィールドは
  同じ語に収まる限り続け，収まらない幅は次の語へ送る
- 普通のメンバを挟むと，詰めは次の語からやり直す
- union のビットフィールドは全て先頭語のビット 0 に重なる
- 幅は 1〜31。型は整数 (ポインタ・構造体は拒む)

### 読み書き (IR の既存演算だけで組む)

- **取り出し** (`rv`): 語を読み，右へ寄せ (`srl`)，幅でマスクする
  (`and`)。マスクが上位を落とすので右シフトの種類には依存しない
- **代入** (`assign`): 読み・修正・書き。語を読み，そのフィールドの
  ビットを消し (`and` に反転マスク)，値をはめて (`and`+`sll`+`or`)
  書き戻す
- **命令種別は足していない。** IR の 4 箇所ルール
  ([dev-notes.md](../docs/dev-notes.md) 4 章) を踏まずに済む

### 拒むもの (対応するまで通さない)

黙って語ごと動かすと**隣のフィールドを静かに壊す**ため，未対応の操作は
拒む (終了コード 5)。

- 複合代入 (`v.a |= 1` など) と `++` / `--`
- `&` (アドレス取得。これは C でも不正)

## 制限

- 値は符号なしとして取り出す (plain `int` のビットフィールドの符号は
  C89 でも処理系定義)
- 無名ビットフィールド (`unsigned : 3;` の詰め物) は未対応
