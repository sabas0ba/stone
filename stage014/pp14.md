# pp14 説明文書

pp14 は C プリプロセッサの Stage 14 第 9 部の世代である。
[../stage009/pp.sc](../stage009/pp.sc) を出発点に，**容量だけを広げた**。
仕組み (フレームの積み・マクロ展開・指令) は pp と同一である。
設計は [stage014-external.md](../docs/stage014-external.md) 13.1 節。

ソース [pp14.sc](pp14.sc) が正本である。

## ビルド

```
sh tools/build.sh stage014
# cc.bin(pp14.sc) -> pp14.o, ld.bin -> pp14.bin   (ld14 と同じ道具立て)
```

SHA-256: df64c22c1ac27973c700f8648abaf1a3201deffe3257e260804409e0fd2c0592

- 対象: RV32IM，リトルエンディアン，53200 バイト
- ロードアドレス: 0x8000_0000 (QEMU virt, `-bios`)

## なぜ要るか

zlib 1.3.1 は pp の器に収まらない。

- crc32.c の束ね (依存ヘッダ込み) が **743 KiB** ある (crc32.h の表)。
  pp の入力上限は 256 KiB
- `INFLATE_ALLOW_INVALID_DISTANCE_TOOFAR_ARRR` (40 文字) がある。
  pp の識別子上限は 31 バイト

いずれも終了コード 6 (容量超過) になり，前処理に入れない。

## pp との差分 (容量のみ)

| 対象 | pp | pp14 |
|---|---|---|
| 入力全体 (src) | 256 KiB | 1 MiB |
| 展開アリーナ (xb) | 256 KiB | 1 MiB |
| マクロ本体 (mbody) | 128 KiB | 256 KiB |
| マクロ定義数 | 512 | 1024 |
| 識別子・マクロ名・メンバ名 | 31 バイト (32 バイトスロット) | 63 バイト (64 バイトスロット) |

## 開発中に踏んだ穴 (記録)

名前スロットを 32 -> 64 バイトへ広げる際，**参照側の添字 (`* 32` ->
`* 64`) だけを変え，仮引数スロットの割付けの進み (`mpp = mpp + 32`) を
変え忘れた**。1 個目の仮引数は位置 0 で一致するため素通りし，2 個目
以降だけが引けなくなる (`#define F(a,b) g(a,b)` が `g(1, b)` になる)。
`ZFREE(strm, addr)` の第 2 引数が展開されないことから発覚した。
スロット幅の変更は読む側と書く側を一組で変えること。

## 制限

- 上限を超えたときの振る舞いは pp と同じ終了コード 6。**部分出力の
  末尾に EOT が付かない**ため，pp の失敗を確かめず次段 (cc) へ
  パイプすると cc が入力待ちで止まる。パイプラインでは pp の終了
  コードを必ず見ること
